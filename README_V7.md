# V7 AI PRO 統一雷達

本版將 AI 操盤雷達 V1 與個人版權證雷達 V6.17 合併。

## 核心原則
- AI 與權證雷達共用同一次真實市場掃描，不再使用 AI V1 隨機示範資料。
- 保留 V6.17：今日推薦、事件型、過熱、連跌+3K-2D、1/3/5日驗證、NEXT、固定關注、權證排行、法人/大戶籌碼說明、事件辨識、資料健康與診斷。
- 保留 AI V1：AI總分、估計勝率、報酬風險比、模擬帳戶、AI錯誤分析、可調權重。
- 法人真實資料尚未串接時明確標示，不製造假分數。

部署時請整包檔案保持同一版本，避免 app.py / radar.py / data_sources.py 版本不同步。
