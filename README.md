# 個人版台股權證雷達 V6.1｜永不空榜實戰版（修正版）

這個版本修正前一個 V6.1 補丁未真正寫入 app.py 的問題。

## 真正生效的 V6.1 功能
- 正式權證預篩為 0 檔時，自動切換到「全市場高流動性保底候選池」。
- 保底池依成交金額 70%＋成交量 30%先找出市場最活躍股票，再做原本的技術評分。
- 今日沒有 ≥70 分股票時，仍顯示「全市場最高分 TOP 10」，不再整頁 0。
- 新增「篩選漏斗診斷」：直接看到股票在哪一關被全部濾掉。
- 新增候選等級：🔥強力候選／🟢今日推薦／🟡NEXT潛在／⚪持續觀察。
- 保留 V6 資料健康檢查、盤中報價覆蓋、即時刷新、權證排行與資金配置。

## 重要
保底候選的目的，是避免『權證資料關聯問題』讓股票候選整頁歸零。
保底股票是否真的適合操作權證，仍必須到權證排行確認成交量、價內外、期限、造市報價。
