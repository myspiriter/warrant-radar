# 個人版台股權證雷達 v6｜盤中實戰版

## v6 核心升級
- 三層資料健康檢查：股票日資料、權證基本資料、權證成交資料。
- 資料缺失時降級運作，不再把「抓不到資料」誤判成「沒有標的」。
- 盤中行情覆蓋：對策略候選前 N 名抓取 TWSE 市況資訊，顯示盤中成交價、漲跌幅、委買、委賣與行情時間。
- 盤中判斷：可觀察進場 / NEXT觀察 / 急漲不追 / 等止穩 / 暫不進場。
- 保留全市場策略掃描、我的關注股、昨日追蹤、權證排行。
- 保留首筆投入與預備金自由設定，單一標的總額上限 NT$500,000。
- 手機可直接使用 Streamlit Cloud，不需要 MacBook 持續開機。

## 重要說明
策略分數以較完整的日線與公開資料計算；盤中資訊是行情覆蓋層，不用瞬間價格取代整個策略。
盤中行情若暫時不可用，App 仍會用最近交易日資料運作。
實際委買賣、成交價、Delta、IV、有效槓桿等交易資訊，下單前請以券商系統為準。
