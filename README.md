# 個人版台股權證雷達 V6.7

## 修正 1：NEXT 第 6 名後沒有盤中資料
舊版只抓全市場 ranking 前 N 名的 MIS 行情，因此 NEXT 頁第 6~10 名常常根本沒有被查詢。

V6.7 改為同時抓：
- 全市場前 N 名
- NEXT 頁前 10 名
- 我的關注股

因此 NEXT 顯示的股票都會主動嘗試取得盤中成交價、漲跌幅、委買、委賣與行情時間。
若 MIS 暫時沒有回報，不再顯示 Python None，而顯示「等待盤中報價」。

## 修正 2：權證履約價/到期日被洗掉
V6.7 重做權證資料 merge：
- 權證基本條款為主表
- 每日成交資料只補成交價、成交量、成交金額、交易日
- 不再覆蓋/洗掉履約價、到期日、發行券商

## 權證價格備援
順序：
1. MIS 最後成交價
2. MIS 委買/委賣中間價
3. 每日資料價格

## 權證計算
只要履約價＋現股價存在，自動算價外幅度。
只要到期日存在，自動算剩餘天數。

Delta / IV / 有效槓桿若沒有券商資料，仍標示「需券商資料」。
