# 個人版台股權證雷達 V6.13

## 核心修正：事件雷達完全獨立
一般選股仍可使用：
現股流動性 → 活躍權證 → 技術評分

事件型股票改成：
全市場高流動性股票 → 直接歷史K線事件掃描 → 事件評分

事件股不再因「活躍權證數不足／權證資料關聯失敗」而在評分前消失。

## 事件型顯示門檻
- 80分以上：🔥 強力事件機會
- 70–79分：🟢 事件型推薦
- 60–69分：🟡 事件型觀察
- 60分以下：不列入事件雷達

事件頁最多顯示前15檔，不是只能有一檔。

## 事件模型
- 事件衝擊 20
- 洗盤品質 20
- 止穩 20
- 反彈確認 20
- 事件風險 20

## 指定股票診斷
即使股票沒有進一般候選池，只要它在獨立事件雷達達60分，
診斷頁仍會顯示它的事件分數與事件等級。


## V6.13 法人／大戶籌碼強化
新增外資、投信、自營商、大戶趨勢與法人/股價背離的 0–20 分籌碼模型。缺漏資料不視為負分，避免公開資料延遲造成錯判。


## V6.13
- 事件型機會新增「事件型原因」欄位。
- 首頁新增「今日市場分析」，依雷達候選強度與事件分布自動總結。


## V6.13 籌碼事件辨識
新增疑似大戶倒貨、籌碼換手、疑似吸籌、洗盤後承接與無法確認；顯示判斷信心、倒貨/換手/吸籌/洗盤機率、大量區防守及原因。T日為初判，T+1～T+3持續確認。

## V6.16 多日驗證
昨日推薦驗證升級為 1日、3日、5日績效驗證。
新增各期命中率、平均報酬、中位數報酬、5日內最高漲幅、5日內最大回撤與整體樣本數。

## V6.17 連跌＋3K-2D弱勢雷達
新增全市場掃描：
- 連續收盤下跌至少3日
- 3K-2D < 0
- 額外標示 K、D 皆 <=20 的超賣股票
- 顯示連跌日數、K、D、3K-2D、KD狀態與最新收盤


## V6.18.5 修正
- 批次KD空結果不再快取6小時；縮短為30分鐘，資料不足自動清快取重試一次。
- 強制更新日K會連同 bulk history cache 一起清除。
- 3K-2D頁新增交易日數、歷史股票數、歷史筆數、負值股票數診斷。
- 今日市場分析不再把前次高分/事件追蹤保留股算入本次有效候選。
- 今日推薦檔數與實際列表使用同一套篩選條件，並新增排除原因診斷。


## V6.18.5
- 修正高速3K-2D掃描回傳(result, diag)未拆包，造成結果永遠無法寫入快取。
- 個股歷史資料失敗/不足時，自動使用批次日K第二層補算，避免今日推薦大量0分。
- 市場平均分數排除資料失敗的0分股票。
- 推薦診斷新增歷史資料來源與有效評分數。
