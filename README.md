# 個人版台股權證雷達 V6.3｜落選原因診斷版

## V6.3 新增
新增「🧪 指定股票診斷」區塊。輸入股票代號（例如 2376）後，可直接看到：

- 股票代號＋公司名稱
- 目前全市場候選排名
- 機會分數
- 訊號類型
- 候選等級
- 盤中判斷
- 現股成交量是否通過
- 現股成交金額是否通過
- 認購權證總數
- 活躍認購權證數
- 是否有進入正式權證預篩
- 未進今日推薦的主要原因

## 典型診斷結果
例如技嘉沒進推薦，可能顯示：
- 機會分數未達 70
- 活躍認購權證不足
- 盤中仍偏弱，等待止穩
- 訊號屬過熱不追
- 沒進入深度評分候選池

這樣之後不需要猜「為什麼沒上榜」，App 會直接說明。

## 保留功能
- V6.2 權證名稱→股票代號備援關聯
- V6.1 永不空榜
- 篩選漏斗
- 盤中行情覆蓋
- 今日推薦 / NEXT / 我的關注股 / 昨日追蹤 / 權證排行
- 投入金額＋預備金可調整，單一標的上限 50 萬元


## 介面修正
- 指定股票診斷改用新的 Streamlit Session State key，避免舊瀏覽器工作階段持續保留 2376。
- 首次載入時股票代號欄位為空白。
