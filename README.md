# 個人版台股權證雷達 v6.1｜永不空榜＋篩選漏斗診斷

## v6.1 升級
- 正式預篩若為 0 檔，不再整頁空白。
- 新增「永不空榜」保底候選池：從全市場依成交金額與成交量找出高流動性股票，再進行深度評分。
- 保底候選僅供觀察；是否適合買權證仍需通過權證頁的流動性、價內外、期限等條件。
- 新增篩選漏斗診斷：
  - 全市場股票
  - 現股成交量門檻
  - 現股成交金額門檻
  - 活躍認購權證門檻
- 新增候選等級：
  - 80–100：🔥 強力候選
  - 70–79：🟢 今日推薦
  - 60–69：🟡 NEXT潛在
  - 50–59：⚪ 持續觀察
- 若沒有 ≥70 分標的，今日推薦頁會顯示全市場最高分 TOP 10，但明確標示「觀察，不代表立即進場」。
- 保留 V6 的資料健康檢查、盤中行情覆蓋與即時刷新功能。
- 首筆投入＋預備金仍可調整，單一標的合計上限 NT$500,000。

## 注意
公開資料與盤中行情可能有延遲或短暫缺漏。實際下單前，請以券商 APP 的即時成交、委買賣、IV、Delta 與造市報價確認。
