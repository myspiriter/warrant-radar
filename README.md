# 個人版台股權證雷達 V6.6

## 修正權證欄位大量 None

V6.6 將權證資料拆成三層補值：

1. TWSE 權證基本資料：履約價、到期日、發行券商、標的等
   - 改用欄名模糊辨識，不再綁死單一欄位名稱。
2. TWSE 權證每日成交：成交量與可取得的成交/收盤價格。
3. TWSE MIS：盤中權證成交價、委買、委賣、盤中量。

發行券商若官方欄位仍缺失，會從權證名稱辨識，例如：
- 友達群益63購03 → 群益
- 所羅門富邦64購01 → 富邦

## Delta / IV / 有效槓桿
這三類資訊若 TWSE 公開資料未提供，V6.6 不再顯示 Python `None`，
而是明確顯示「需券商資料」。若未來上傳券商 CSV 或串券商 API，
原本的欄位會自動使用實際資料。

## 保留
- 個股推薦 TOP 3
- 每檔個股權證 TOP 5
- 指定股票診斷
- 多重股票資料來源
- 盤中行情覆蓋
