# 個人版台股權證雷達 v5.2｜全市場動態掃描穩定版

## v5 核心升級
- 每日自動掃描 TWSE 上市股票，不再只分析固定追蹤清單。
- 第一層先篩：現股成交量、成交金額、有無認購權證、活躍權證數。
- 第二層對候選股做歷史量價/趨勢/位置/動能評分。
- 「今日推薦」最多顯示 10 檔，但不會為了湊滿 10 檔而降低門檻。
- 「NEXT 潛在標的」顯示接近條件、尚未完全觸發的股票。
- 「我的關注股」獨立保留，可自行增刪。
- 股票一律顯示「代號＋公司名稱」。
- 主要欄位全面中文化。
- 權證預設使用 TWSE 上市權證基本資料＋每日成交量；若上傳券商 CSV，可補 Delta、IV、即時買賣價差等欄位。
- 首筆投入與預備金皆可調整，合計上限 50 萬元。

## 資料限制
TWSE 公開資料適合每日/盤後掃描，但不是券商逐筆即時行情。若要做真正盤中「最佳權證」判斷，
建議後續串接合法券商行情 API，尤其是委買賣、Delta、IV、有效槓桿。

## Streamlit Cloud 更新
把本資料夾內檔案上傳覆蓋 GitHub `warrant-radar` repository 的同名檔案。
Streamlit Cloud 會偵測 GitHub commit 並自動重新部署。


## v5.1 修正
- 修正全市場掃描結果為空時 `ranking.score` 造成的 AttributeError。
- 補上空資料與缺欄位防呆，不再因 TWSE 回傳異常而整個 App 中斷。
- 無候選股時會顯示中文提示，固定關注股仍可使用。

## v5.2 修正
- 修正 Header metrics 在空資料時仍先讀取 `ranking["score"]` 的 KeyError。
- `stock_ranking()` 與 `dynamic_ranking()` 現在即使沒有任何資料，也會回傳具完整欄位的空表。
- 所有首頁統計之前新增統一欄位標準化 gate。
- 休市、資料源空值或當日沒有候選標的時，App 應顯示提示而不是整頁中斷。
