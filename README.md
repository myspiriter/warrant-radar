# 個人版台股權證雷達 V6.2｜權證資料關聯修正版

V6.2 專門修正「股票有候選，但權證排行為空」問題。

## 三層權證關聯
1. 優先使用 TWSE 權證基本資料中的官方標的證券代號。
2. 官方標的欄位缺失或欄名變動時，由權證名稱反推標的：
   - 技嘉富邦61購01 → 技嘉 → 2376
   - 台積電元大購01 → 台積電 → 2330
3. 若基本資料仍失敗，從每日權證成交資料的名稱建立最低限度備援關聯。

## 其他修正
- 認購/認售同時參考官方欄位與權證名稱「購/售」。
- 權證成交量欄位支援多種 TWSE 欄名。
- 資料健康檢查新增：權證基本筆數／可辨識股票標的筆數／認購權證筆數。
- 保留 V6.1 永不空榜、篩選漏斗、盤中行情與資金配置。

## 預期
原本漏斗若為：
366 → 具有認購權證 0

V6.2 應能變為：
366 → 具有認購權證 N → 至少有活躍認購權證 N

實際數量會依資料日期及你設定的權證最低成交量而變動。
