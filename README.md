# 個人版台股權證雷達 V6.12

## 核心修正：事件雷達完全獨立
一般選股仍可使用：
現股流動性 → 活躍權證 → 技術評分

事件型股票改成：
全市場高流動性股票 → 直接歷史K線事件掃描 → 事件評分

事件股不再因「活躍權證數不足／權證資料關聯失敗」而在評分前消失。

## 事件型顯示門檻
- 80分以上：🔥 強力事件機會
- 70–79分：🟢 事件型推薦
- 60–69分：🟡 事件型觀察
- 60分以下：不列入事件雷達

事件頁最多顯示前15檔，不是只能有一檔。

## 事件模型
- 事件衝擊 20
- 洗盤品質 20
- 止穩 20
- 反彈確認 20
- 事件風險 20

## 指定股票診斷
即使股票沒有進一般候選池，只要它在獨立事件雷達達60分，
診斷頁仍會顯示它的事件分數與事件等級。


## V6.12 法人／大戶籌碼強化
新增外資、投信、自營商、大戶趨勢與法人/股價背離的 0–20 分籌碼模型。缺漏資料不視為負分，避免公開資料延遲造成錯判。


## V6.12
- 事件型機會新增「事件型原因」欄位。
- 首頁新增「今日市場分析」，依雷達候選強度與事件分布自動總結。
