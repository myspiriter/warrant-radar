# 個人版台股權證雷達 V6.4

## V6.4 核心修正：全市場資料多重容錯
上一版若 TWSE `STOCK_DAY_ALL` 單一來源暫時失敗，整個全市場候選會變成 0。V6.4 改成依序嘗試：

1. TWSE OpenAPI：`/exchangeReport/STOCK_DAY_ALL`
2. TWSE 官方 open_data CSV：`STOCK_DAY_ALL?response=open_data`
3. TWSE 官方 `MI_INDEX` 最近交易日 JSON
4. 本次 Streamlit instance 最後一次成功的 last-good 快取

## 畫面新增
- 資料健康檢查顯示「市場資料來源」
- 標示主來源 / 備援來源 / 快取備援
- 顯示抓取時間
- 新增「♻️ 重新抓取全市場資料」按鈕
- 所有來源皆失敗時，明確顯示「資料源異常」，不再誤導為 0 檔股票

## 保留功能
- 指定股票診斷：沒有輸入代號就不顯示資料
- V6.3 落選原因診斷
- V6.2 權證名稱反推標的股票
- 永不空榜與篩選漏斗
- 盤中行情覆蓋
- 今日推薦 / NEXT / 我的關注股 / 昨日追蹤 / 權證排行
- 首筆投入＋預備金可調，單一標的上限 50 萬元

## 資料說明
策略掃描仍以 TWSE 官方公開資料為主。即使使用備援來源，實際下單前仍應以券商即時成交、委買賣、IV、Delta 與造市報價確認。
